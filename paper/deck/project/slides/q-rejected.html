B31

Each hypothesis was chosen so that either outcome is informative. If joint scaling does not remove the saturation increase, the conclusion is that feasibility of commitments is not enough and a saturation-aware constraint is needed. If the weak-coupling plants do not show an oracle gain above about 5 percent, or TD3 still does not beat the tuned VSG there, then the result is that a tuned VSG with the feasibility layer is sufficient, and the oracle has done its job by saving the training effort. If EMT contradicts the averaged model on small gains, the thesis will specify which metrics need circuit-level checks. Source: Section 1.8, Table 1.2.
