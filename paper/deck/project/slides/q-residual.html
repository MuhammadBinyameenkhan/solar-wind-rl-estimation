Q: Why residual RL, and why was the untrained agent selected?

Why residual

The actor's output layer starts at zero, so the untrained policy is the tuned VSG. The agent only has to learn corrections, and a = 0 is a safe fallback.

What happened

For nine of ten constrained runs the best validation checkpoint was episode 0, the tuned VSG itself (validation return −82.03). The tenth was 0.5 % better on validation but 3.9 % worse on test.

Why that is a result

It agrees with the oracle: at most 1.3 % to gain in this plant. Model selection that includes the base controller is what reveals it.

Residual learning, after Silver et al. 2018, makes the tuned VSG the starting point: the actor's last layer is zero-initialised, so action zero is the tuned controller and the agent only learns corrections. Model selection evaluated the validation return every 50 episodes and included the untrained agent. For nine of the ten constrained runs, TD3 and DDPG, the best checkpoint was episode zero, the tuned VSG, with a validation return of minus 82.03. The tenth, TD3 seed 3, found a checkpoint half a percent better on validation, but it was about four percent worse on the test scenarios, which is what over-fitting a small validation set looks like. I report the final policies as the learned controllers. This is not a failed training; it is the same message as the oracle bound: in this coupled plant there is very little left to learn.
