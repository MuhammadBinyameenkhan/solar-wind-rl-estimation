Q: Were the baselines fair?

Same data

Every controller sees the same scenarios, operating points and noise sequences; tuning uses validation data only, testing uses 200 unseen test scenarios.

Same objective

The fixed VSG (3 s, 15 pu) and the rule-based VSGs are tuned on validation data with the same cost the agents optimise.

Same plant limits

The rate limiter and feasibility layer are applied identically to every controller.

B18

The main criticism of the learning-VSG literature is untuned or hand-picked baselines, so fairness is built into the protocol. Every controller is tuned on validation data with the same objective, tested on the same unseen scenarios with the same noise, and passes the same rate limiter and feasibility layer. The tuned fixed VSG in Study 1 is interesting: zero inertia and 35 per-unit damping, which again shows that damping does most of the work. Source: Section 3.9, Tables 4.1, 4.3, 4.4.
