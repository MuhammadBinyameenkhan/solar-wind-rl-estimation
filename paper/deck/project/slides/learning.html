A residual TD3 agent on top of a tuned VSG

Interval cost (50 ms)

Penalises Δf outside ±0.2 Hz, RoCoF above 1 Hz/s, fast VSG power, BESS use, saturation and violations.

Weights (1, 0.02, 0.5, 2, 0.1, 2, 1); return R = −Σ c

Residual action

a = 0 is the validation-tuned VSG (3 s, 15 pu, α = 1); same for D_v and α. 16 normalised observations.

TD3 critic target

Two critics, smallest target, clipped target noise, delayed actor (Fujimoto 2018). DDPG uses one critic. 5 seeds × 1000 episodes.

Scheduling is a Markov decision process with a 50 millisecond decision interval. The cost penalises frequency only outside the plus-minus 0.2 hertz band and RoCoF only above 1 hertz per second, together with fast VSG power, battery use, saturation and violations. The weights were chosen so that the best fixed setting has an interior damping; with a plain quadratic penalty, maximum damping always won and the problem became trivial. The action is residual: zero output reproduces the tuned VSG, and the actor's output layer starts at zero, so the untrained agent is exactly the tuned controller. TD3 uses two critics and the smaller target to avoid overestimation.
