B3

The thesis is a simulation study with a clearly stated scope, Section 1.5. Each simplification has a known effect and a way it is handled. The EMT model in Simscape was built precisely to test what the averaged model neglects: network electromagnetics, nonlinear power–angle relation, voltage and reactive power, the PLL and a limiter acting on measured power. Converter switching is far faster than the 50 ms decision time, so an average model is standard. The load profile is synthetic; measured Thai data would replace it if available. Hardware-in-the-loop is planned only if facilities allow, and I do not promise it.
