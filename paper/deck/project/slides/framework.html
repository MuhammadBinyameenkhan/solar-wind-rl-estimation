3 · Methodology · framework

Inputs → models → control layer → evaluation

M. B. Khan · Feasible synthetic inertia · Proposal defence

13

This is the conceptual framework. Real weather data, randomised load events and grid-code limits feed two microgrid models. The control layer has three parts in a fixed order: the DRL agent proposes inertia and damping, a rate limiter smooths them, and the headroom feasibility layer has the last word, so feasibility takes priority over smoothness. The evaluation has three pillars: fair benchmarking against tuned controllers over several seeds, an oracle bound computed before any training, and validation beyond the averaged model.
