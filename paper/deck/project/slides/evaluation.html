The evaluation has three layers. First, before training anything, the oracle bound: I simulate a grid of 24 fixed settings on 40 validation scenarios and compare a scheduler that picks the best setting per scenario with the best single setting. If that gap is small, no scenario-level adaptive controller can do much better than a tuned VSG. Second, a fair comparison: every baseline is tuned on validation data with the same objective, checkpoints are selected on validation with the untrained agent as a candidate, and paired Wilcoxon tests with Holm correction are used over 200 test scenarios. Third, validation in a chain: an independent MATLAB implementation, then a three-phase Simscape model.
